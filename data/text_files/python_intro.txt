Python Programming Introduction


    1. WHAT IS PYTHON?
--------------------------------------------------------------------------------
Python is a high-level, interpreted programming language known for:
  - Simple, readable syntax
  - Large ecosystem (AI, web, data science, automation)
  - Cross-platform (Windows, Mac, Linux)
Used in: AI/ML, web apps (Django, Flask), scripting, automation, data analysis.

4. VARIABLES AND DATA TYPES
--------------------------------------------------------------------------------
Variables store data. No need to declare type explicitly.
name = "Rahul"          # str (string)
age = 25                # int (integer)
height = 5.9            # float (decimal)
is_student = True       # bool (True/False)
print(type(name))         # <class 'str'>
Type conversion:
  x = int("10")
  y = str(100)
  z = float("3.14")
5. OPERATORS
--------------------------------------------------------------------------------
Arithmetic:  +  -  *  /  //  %  **
  Example: 10 // 3 = 3, 10 % 3 = 1, 2 ** 3 = 8
Comparison:  ==  !=  >  <  >=  <=
Logical:     and  or  not
Assignment:  =  +=  -=  *=  /=
6. STRINGS
--------------------------------------------------------------------------------
text = "Hello"
name = 'Python'
msg = f"My name is {name}"    # f-string (formatted string)
Common methods:
  text.upper()
  text.lower()
  text.strip()
  text.replace("H", "J")
  len(text)
Slicing:
  text[0]       # 'H'
  text[1:4]     # 'ell'
  text[:3]      # 'Hel'
  text[2:]      # 'llo'

9. LOOPS
--------------------------------------------------------------------------------
# for loop
for i in range(5):
    print(i)          # 0, 1, 2, 3, 4
for char in "Python":
    print(char)
# while loop
count = 0
while count < 3:
    print(count)
    count += 1
break    -> exit loop
continue -> skip to next iteration
10. LISTS (ordered, changeable)
--------------------------------------------------------------------------------

fruits.append("mango")
fruits.remove("banana")
fruits[0] = "orange"
print(len(fruits))
List comprehension:
  squares = [x * x for x in range(5)]

12. DICTIONARIES (key-value pairs)
--------------------------------------------------------------------------------
person = {
    "name": "Rahul",
    "age": 25,
    "city": "Delhi"
}
print(person["name"])
person["email"] = "rahul@example.com"
print(person.get("phone", "N/A"))
for key, value in person.items():
    print(key, value)

14. FUNCTIONS
--------------------------------------------------------------------------------

  return a + b
# *args and **kwargs
def show(*args, **kwargs):
  print(args)
  print(kwargs)

16. CLASSES AND OBJECTS (OOP)
--------------------------------------------------------------------------------
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def introduce(self):
        return f"I am {self.name}, age {self.age}"
p = Person("Rahul", 25)
print(p.introduce())

def count_vowels(s):
    vowels = "aeiou"
    return sum(1 for ch in s.lower() if ch in vowels)
